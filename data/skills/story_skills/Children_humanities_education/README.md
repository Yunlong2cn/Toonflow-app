# 儿童人文通识 · 导演叙事手法技能包

## 简介

本技能包面向“给孩子讲课文、节气、名画、寓言、历史人物”的人文教育短视频。它不是传统知识讲解，也不是历史史诗，而是通过现代孩子的真实疑问，把文化对象带入一个可进入、可看见、可共情的文化现场。

## 核心理念

- **孩子的问题必须真实幼稚**：开头从孩子会问的问题切入，例如“不就是一座桥吗”“立夏不就是夏天来了吗”。孩子负责不懂，内容负责讲透。
- **古人不是讲师，是带路人**：古人不坐着讲概念，而是带孩子看河、看桥、看麦田、看画里的人、看一盏灯。
- **知识点必须变成人生隐喻**：课文结构、节气习俗、文物细节都只是入口，最终要落到孩子能带走的一种活法。
- **父母视角提供转发理由**：视频本体面向孩子，发布文案面向家长。家长转发的理由不是“长知识”，而是“我也想让孩子明白这个”。
- **克制而有余韵**：不把结尾写成鸡汤口号，金句必须从前面的场景和人物选择里自然长出来。
- **事实边界优先**：课文原意、历史人物、节气知识、名画细节、典故出处必须尊重可验证资料。资料不确定时，只能写成“想象化教学场景”，不能当作史实陈述。

## 适用范围

- 小学语文课文、文言文、古诗词、名画、文物、节气、传统节日、考试节点、成长节点。
- 亲子文化解释类人文教育短视频、教育类短剧、儿童人文通识内容。
- 需要“孩子提问 + 历史现场 + 古人带路 + 人生落点”的内容。

## 不适用范围

- 纯百科知识讲解。
- 单纯历史人物传记。
- 成人权谋、战争史诗、玄幻仙侠、甜宠言情。
- 只靠旁白堆知识点、没有孩子视角和情绪落点的内容。

## 使用方式

本技能包用于导演规划与分镜表阶段，指导 Agent 生成：

1. 选题切口：从课本/节气/文化对象里找一个被忽略的细节。
2. 视频结构：孩子提问、进入现场、古人带路、反常识转折、价值落点。
3. 分镜语言：现代孩子、历史人物、文化现场、象征大景、黑底金句。
4. 发布文案：父母札记式表达，补足家长收藏和转发理由。
5. 爆款传播：前三秒钩子、封面悬念、标题冲突、评论区置顶话术必须服务同一个核心疑问。

## 标准输出格式

使用本技能包生成单条视频方案时，建议按以下结构输出：
[config](..%2F..%2F..%2F..%2F.git%2Fconfig)
1. 片名与选题切口
2. 事实依据与不确定边界
3. 核心隐喻与价值落点
4. 视频脚本（孩子台词、父母引导、古人带路、旁白）
5. 分镜表（镜头编号、时长、景别、运镜、画面内容、声音/音乐、叙事功能）
6. 画面提示词要点
7. 发布文案（父母札记口吻）
8. 标题、封面文案、评论区置顶话术

黑底金句、标题字、封面字属于后期制作内容，不进入画面生成提示词。

## 爆款短视频约束

- **前三秒必须有钩子**：每条开头至少满足“反常识、亲子痛点、悬念细节”之一，不能从百科定义开始。
- **每条必须有传播理由**：明确这条内容为什么值得家长转发、老师收藏、成年人共鸣或评论区讨论。
- **标题和封面不能平铺**：不要只写“给孩子讲 XXX”，要写出冲突或悬念，例如“孩子背会了赵州桥，却没懂这座桥为什么值得造”。
- **评论区置顶要补一刀**：置顶话术用于强化转发理由或抛出讨论问题，不能只是重复标题。
