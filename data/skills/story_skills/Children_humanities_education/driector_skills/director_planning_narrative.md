# 叙事手法 · 儿童人文通识 · 技法参考

## 一、主题立意与内容内核

- **表层是知识，底层是活法**：每条视频都要从一个知识对象进入，但结尾不能停在知识点。赵州桥不是桥梁结构，而是“见他人之苦”；立夏不是民俗百科，而是“天地有时序”；高考不是考试说明，而是“一次翻山”。
- **父母想说但说不清的话**：主题要替家长表达“我不只是想让孩子考试好，我想让她懂得为什么学”。这是收藏和转发的核心。
- **一个细节撬动整条视频**：优先找可复述的细节，例如一个字、一个被忽略的动作、画里一个抬头的人、一句史料、一个节气时刻。
- **孩子视角保持低门槛**：孩子的问题不要高深，越朴素越好。不要让孩子像小博士，孩子应该代表真实的不懂、误解和第一反应。
- **文化对象必须可进入**：不要抽象解释“文化很重要”，要让孩子走进桥边、麦田、古城、山路、画卷、书桌和夜院。
- **事实边界先于情绪升维**：课文、文言文、古诗、节气、名画、历史人物、典故出处必须以可验证资料为依据。可以做想象化教学场景，但必须避免把想象当作史实。

## 二、资料依据与事实边界

### 必须遵守

- **课文类**：不得篡改课文原意，不得把现代价值判断伪装成教材本意。
- **历史人物类**：不得编造生平、言论、官职、年代、人物关系。史料缺失时，只能写“我们想象他可能站在这里”，不能写成确定事实。
- **节气类**：天文、农事、民俗要区分清楚。民俗有地域差异时，不要写成全国统一习俗。
- **名画/文物类**：画中细节、作者身份、时代背景必须谨慎，不能为了爆点制造不存在的“秘密”。
- **古诗词类**：修辞解释可以儿童化，但不能违背诗句基本含义。

### 允许的创作方式

- 可把抽象知识可视化成桥、山、灯、麦田、河流等隐喻。
- 可让古人作为“带路人”与孩子对话，但对话本身默认是教学化虚构。
- 可补足普通人群像和历史现场，但要服务于已知事实或合理推演。
- 对不确定资料，应在输出中单列“事实依据与不确定边界”。

## 三、标准视频结构

| 阶段 | 功能 | 写法 |
|---|---|---|
| 前三秒钩子 | 用反常识/痛点/悬念抓住观众 | “这篇课文，孩子背下来了，但其实没读懂”“很多家长讲错了这个节气” |
| 现实问题 | 抓住孩子和家长的共同入口 | “爸爸，这篇课文太难了”“立夏就是夏天来了吗” |
| 进入现场 | 把抽象知识变成可见场景 | “这个问题爸爸讲不清，你去问问他” |
| 第一层答案 | 解释表层知识 | 古人带孩子看具体场景，不直接讲概念 |
| 反常识转折 | 让内容变深 | “你看到的是桥，但真正重要的是过不了河的人” |
| 情绪加压 | 触发成年人共鸣 | 普通人的苦、孩子的困惑、父母的无力、人生的不确定 |
| 价值落点 | 形成可转发记忆点 | 一句从剧情里长出来的人生话 |
| 余韵收束 | 留情绪，不解释满 | 远景、背影、后期黑底字、诗词或安静停顿 |

一句话模板：**孩子以为自己在学一个知识点，最后发现自己在学习一种活法。**

## 四、选题筛选标准

一个选题能不能做，先问五个问题：

1. 孩子会不会天然疑惑？
2. 家长有没有转发理由？
3. 有没有一个古人、历史人物或文化对象能带路？
4. 有没有一个可视化大隐喻？
5. 结尾能不能落到一句人生话？

少于四个“是”，不适合作为第一批视频。

## 五、爆款钩子与传播触发器

### 前三秒钩子

每条开头必须至少命中以下一种：

- **反常识钩子**：观众以为懂了，其实没懂。例如“赵州桥最重要的，不是它有多坚固。”
- **亲子痛点钩子**：家长正在焦虑、孩子正在误解。例如“孩子会背节气歌，但未必知道节气为什么和自己有关。”
- **悬念细节钩子**：一个画面、一个字、一个动作牵引观看。例如“清明上河图里，为什么只有那个人抬头？”

禁止用百科式开头，例如“今天我们来讲赵州桥”“立夏是二十四节气之一”。

### 传播触发器

每条视频必须明确一个主要传播理由：

- **家长转发**：这段话替我说出了我想让孩子懂的事。
- **老师收藏**：这个角度可以用于课堂导入或作文启发。
- **成年人共鸣**：借孩子的课本重新解释我的人生处境。
- **评论讨论**：这个解释是否准确、是否击中你、你会怎么讲给孩子。

### 标题与封面公式

- 标题公式：`给孩子的XXX + 一个反常识角度`，或 `孩子以为A，其实B`。
- 封面文案公式：`一句冲突/悬念短句`，少于 16 个汉字优先。
- 避免平铺标题：不要只写“给孩子讲赵州桥”“二十四节气科普”。
- 封面字只作为后期制作，不进入画面生成提示词。

### 评论区置顶

置顶话术要补充传播理由或引导讨论，例如：

- “你会怎么给孩子解释这篇课文？”
- “你小时候背过，但长大后才读懂的是哪一课？”
- “这条适合收藏，等孩子学到这篇课文时再一起看。”

## 六、常见选题模型

| 类型 | 结构模板 | 示例方向 |
|---|---|---|
| 课文 | 孩子只记住知识点 -> 走进文本背后的现场 -> 发现普通人的处境 | 赵州桥、司马光、铁杵成针 |
| 节气 | 孩子会背名字 -> 古人带她看天时与农事 -> 节气变成人生节奏 | 立夏、芒种、小满、冬至 |
| 名画/文物 | 孩子只看到热闹 -> 发现被忽略的细节 -> 细节指向时代与人 | 清明上河图、千里江山图 |
| 古诗词 | 孩子只背句子 -> 诗人带她看真实处境 -> 修辞变成看世界的方法 | 望庐山瀑布、登鹳雀楼 |
| 人生节点 | 孩子害怕一个节点 -> 用大隐喻视觉化压力 -> 告诉孩子如何面对 | 高考、毕业、开学、青春期 |

## 七、人物功能

- **孩子**：负责真实疑问、误解和情绪代入。台词短，问题直，不承担解释任务。
- **父亲/母亲**：负责把孩子送入文化现场，也负责发布文案里的家长视角。视频中少讲大道理。
- **古人/历史人物**：负责带路，不做讲师。每一个知识点都要绑定一个动作或场景。
- **普通人群像**：负责让知识落地。例如过不了河的百姓、麦田里抢收的人、画卷里低头谋生的人。

## 八、情绪与声音方向

- **旁白压强高，镜头节奏慢**：不追求短视频硬切快感，使用慢镜头、凝视、背影和大景承托文字。
- **配乐克制**：避免煽情堆满，关键转折处可降低配乐，让人声、风声、水声、脚步声承担情绪。
- **黑底字只用于后期收束**：黑底金句不频繁出现，主要放在章节断点或最后一句。黑底字、标题字、封面字属于后期制作内容，不进入画面生成提示词。
- **发布文案独立写**：视频脚本面向孩子，发布文案面向家长。发布文案要解释“我为什么给孩子做这条视频”。

## 九、标准输出格式

生成单条视频方案时，建议按以下结构输出：

1. 片名与选题切口
2. 事实依据与不确定边界
3. 核心隐喻与价值落点
4. 视频脚本（孩子台词、父母引导、古人带路、旁白）
5. 分镜表（镜头编号、时长、景别、运镜、画面内容、声音/音乐、叙事功能）
6. 画面提示词要点
7. 发布文案（父母札记口吻）
8. 标题、封面文案、评论区置顶话术

## 十、避免事项

- 不要把古人写成现代老师讲 PPT。
- 不要让孩子输出成人化金句。
- 不要堆百科知识，必须有一个主隐喻贯穿。
- 不要把价值落点写成空泛鸡汤。
- 不要每条都强行“穿越”。这里的“进入现场”是教育表达中的可视化文化现场，不是玄幻穿越、时空隧道或魔法设定。若文化对象本身可视化足够强，也可以进入画卷、梦境、山路或记忆现场。
