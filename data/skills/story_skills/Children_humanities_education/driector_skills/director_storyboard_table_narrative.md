# 分镜表叙事手法 · 儿童人文通识

## 一、分镜表定位

儿童人文通识视频的分镜表不是把旁白机械拆成画面，而是把“一个知识点如何被孩子亲眼看见”拆成可执行镜头。每个镜头都应回答：孩子看见了什么、这个画面如何改变她对知识点的理解、家长为什么会愿意转发。

## 二、固定镜头模块

| 模块 | 镜头功能 | 常用画面 |
|---|---|---|
| 前三秒钩子 | 快速建立反常识/痛点/悬念 | 孩子困惑表情、课本特写、一个异常细节、父亲一句悬念旁白 |
| 现代孩子 | 代入入口 | 校服孩子、书桌、语文书、作业本、窗边发问 |
| 文化入口 | 从现实进入现场 | 父亲一句话、书页翻动、画卷展开、山路显现 |
| 古人带路 | 知识场景化 | 古人不正面讲课，而是带孩子看桥、河、灯、麦田、古城 |
| 普通人处境 | 让知识有重量 | 等船的人、抢收的农人、夜读的书生、街市里的百姓 |
| 象征大景 | 承托隐喻 | 桥、山、河、麦浪、星空、古城、雨、灯 |
| 细节特写 | 承载反常识 | 手、脚、石头、小拱、书页上的字、画卷角落 |
| 后期黑底金句 | 情绪收束 | 后期居中文字，少量出现，句子必须来自剧情，不进入画面生成提示词 |

## 三、景别策略

- **开头用近景**：孩子的脸、书本、作业场景，把入口做低。
- **解释知识用中景和动作**：让古人和孩子同框，不要只有人物口播。
- **情绪加压用远景**：把孩子放进大桥、大山、麦田、古城、河流里，让她显得小，知识显得大。
- **转折用特写**：一个字、一个小拱、一盏灯、一粒种子、一根琴弦，承担“原来重点在这里”的瞬间。
- **结尾用背影或大景**：不要用人物正脸强行煽情，优先让余韵留在空间里。

## 四、运镜节奏

| 段落 | 运镜建议 | 节奏 |
|---|---|---|
| 前三秒钩子 | 快速近景/特写/一句旁白 | 直接给疑问，不铺垫 |
| 现实开场 | 固定或轻微手持 | 稳、近、生活感 |
| 进入现场 | 缓推、书页/画卷匹配转场 | 有一点神秘，但不玄幻 |
| 古人带路 | 跟拍、横移、主观视角 | 像孩子真的走在现场 |
| 反常识揭示 | 固定凝视或缓推特写 | 慢下来，让观众听懂 |
| 情绪加压 | 大景缓拉、背影跟拍 | 让空间压住人物 |
| 价值落点 | 静止、缓拉、后期黑底字 | 留白，不解释满 |

## 五、时长把控

- 现实开场：5%-10%，快速抛出孩子的问题。
- 进入现场：5%-10%，不要拖成奇幻设定。
- 第一层答案：20%-30%，把知识点讲清楚。
- 反常识转折：20%-25%，这是视频变深的核心。
- 情绪加压：20%-25%，让家长产生共鸣。
- 价值落点：10%-15%，一句金句加一个余韵镜头。

前三秒单独设计，不从总时长里平均分配。开头镜头必须让观众立刻知道“这条不是普通科普”，而是有一个课本背后的误解、悬念或亲子痛点。

## 六、台词与旁白

- 孩子台词短：一句问题，一句追问，一句“可是……”
- 古人台词要场景化：少说“这个道理是”，多说“你看那条河”“你看这粒种子”。
- 父母台词克制：视频里少讲，发布文案里再展开。
- 金句不要先写：先让剧情推到那里，再提炼最后一句。

## 七、分镜表字段建议

每个镜头至少包含：

- 镜头编号
- 时长
- 场景
- 人物
- 景别
- 运镜
- 画面内容
- 台词/旁白
- 声音/音乐
- 叙事功能
- 画面提示词要点
- 事实依据/虚构边界
- 传播触发器（家长转发/老师收藏/成年人共鸣/评论讨论）
- 标题与封面文案（后期文字，不进入画面生成提示词）

## 八、发布文案联动

视频脚本之外，还要补一份发布文案。分镜表里可标记哪些画面适合成为发布文案中的“父母札记”素材，例如：

- “我为什么想让孩子懂这个”
- “孩子平时只看见了什么”
- “我查资料后发现了什么”
- “这个发现对孩子意味着什么”
- “我希望她最后带走什么”

## 九、避免事项

- 不要把所有镜头做成古人正面讲解。
- 不要让黑底字替代剧情推进。
- 不要把黑底字、标题字、封面字写进画面生成提示词；这些文字由后期制作完成。
- 不要用平铺标题和百科式开头；前三秒必须有反常识、痛点或悬念。
- 不要用过多奇幻特效解释文化内容。
- 不要为了画面好看牺牲知识准确性。
- 不要把儿童教育视频做成成人历史纪录片。
