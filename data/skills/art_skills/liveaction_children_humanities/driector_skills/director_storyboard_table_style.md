# 分镜表风格 · 真人儿童人文通识

## 一、分镜表风格字段

每个镜头的画面提示词建议包含：

- 时代：现代入口 / 历史现场 / 象征大景。
- 主体：现代孩子、古人、父母、普通人群像、关键道具。
- 动作：提问、带路、观察、触摸、回望、同行、劳作。
- 景别：近景、中景、特写、全景、大全景。
- 运镜：固定、缓推、缓拉、跟拍、轻微手持。
- 光源：窗光、天光、夕阳、油灯、阴天漫射光。
- 风格锁定：真人实拍电影质感、低饱和自然光、无字幕无水印。

## 二、镜头组合建议

| 段落 | 镜头组合 |
|---|---|
| 前三秒钩子 | 孩子困惑近景 + 课本/细节特写 + 悬念旁白 |
| 现实问题 | 孩子近景 + 课本特写 + 父母侧影 |
| 进入现场 | 书页/画卷/门口转场 + 孩子抬头 + 历史场景中景 |
| 古人带路 | 双人中景 + 跟拍 + 普通人群像 |
| 反常识转折 | 关键细节特写 + 孩子反应近景 |
| 情绪加压 | 普通人处境 + 空间大景 + 古人沉默 |
| 价值落点 | 背影远景 + 安静空镜 + 后期黑底字 |

## 三、同框规则

- 现代孩子与古代人物同框时，孩子服装保持现代，不要自动换古装。
- 同框画面必须有自然视线关系，古人低头看孩子，孩子抬头听。
- 避免人物像抠图拼接，统一光源方向和色彩温度。

## 四、后期文字规则

画面生成阶段不直接生成黑底字、标题、字幕。若需要黑底金句，应在分镜表中标注“后期黑底字”，画面提示词仍要求无字幕、无水印、无标题叠字。

封面图可以使用孩子困惑表情、课本特写、古人侧影、桥/山/麦田等强识别画面，但封面标题字由后期制作完成，不写入画面生成提示词。
