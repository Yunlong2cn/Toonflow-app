# 真人儿童人文通识影像风格

## 简介

本风格专为“现代孩子进入课文、节气、名画、寓言、历史现场”的人文教育短视频打造。画面基准是真人实拍级电影质感：现代孩子有真实校园和家庭生活感，古代人物和历史场景有写实影视剧质感，二者通过统一的摄影机语言、低饱和色彩和自然光影融合为同一条视频。

## 核心风格定义

- **真人实拍电影感**：所有角色、场景、道具必须读作摄影机拍摄，而非 3D 渲染、插画、二次元或游戏 CG。
- **现代孩子代入点**：常见形象为中国小学生，校服、眼镜、书包、语文书、书桌、教室、家中窗边，表情真实自然。
- **历史现场写实化**：古人、古桥、古城、麦田、夜读院落、画卷街市等都要有真实材质、生活痕迹和时代可信度。
- **文化寓言气质**：画面不追求热闹炫技，而追求慢镜头、凝视、背影、大景和手部特写形成的余韵。黑底金句由后期制作完成，不直接生成在画面中。
- **统一摄影语言**：现代段落与历史段落都遵循同一套电影摄影规则，避免“现代像纪录片、古代像游戏 CG”的割裂。

## 适用范围

- 课文、文言文、古诗、节气、名画、文物、寓言、历史人物、考试节点等亲子人文教育视频。
- 现代孩子与古代人物同框、孩子走进历史现场、父母视角文化解释类内容。
- 需要低饱和、克制、电影感、真人写实的人文教育短视频图像和视频生成。

## 严禁内容

- 二次元、插画、卡通、Q版、国漫、赛璐璐。
- 3D 渲染、CG、UE、Blender、PBR、游戏建模、塑料皮肤。
- 玄幻仙术、夸张光效、神话化特效、过度穿越特效。
- 现代孩子成人化、网红化、写真化、摆拍感。
- 古代场景无历史依据、服饰混搭、廉价影楼风。
- 高饱和滤镜、荧光色、赛博朋克、恐怖血腥、擦边内容。
- 直接生成字幕、标题字、黑底金句、平台水印、LOGO、UI 元素。

## 风格体验

在本风格下，画面应该像一部给孩子看的高品质人文电影：孩子站在桥边、麦田、古城和画卷街市里，听古人用一个具体场景解释课本背后的意义。画面克制、真实、有文化重量，不炫技，不做知识 PPT。
